## Nunito Sans

The bundled Nunito Sans font files in `src/main/resources/fonts/`
(`NunitoSans-Regular.ttf`, `-SemiBold.ttf`, `-Bold.ttf`, `-ExtraBold.ttf`) are
licensed under SIL Open Font License 1.1. The license text is available at
`src/main/resources/licenses/OFL-Nunito-Sans.txt`.

Four static weights are bundled instead of the variable font: the JDK renders a
variable font through its default instance only, so every weight collapsed to
Nunito Sans ExtraLight and all interface text looked far thinner than the
approved design.
